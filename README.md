# HRSG Maintenance Decision Support Platform

복합화력 발전소 엔지니어를 위한 AI 질의응답 + 성능·경제성 계산기

HRSG Reference App (폐열회수단 × 클라우드라 협력 프로젝트)

> **UI PROTOTYPE · MOCK DATA ONLY** — 기업 데이터 수령 전입니다. 화면에 표시되는 수치, 운전 조건, 가격, 비용, 편익, 기준값, 시계열 데이터는 모두 시연용 가상 데이터입니다. 계산식은 입력과 출력의 연결을 확인하기 위한 **예시 계산**이며, 실제 HRSG 성능을 검증한 공학 모델이 아닙니다.

## 빠른 시작

```bash
npm install         # 의존성 설치
npm run dev         # 개발 서버 → http://localhost:5173
npm run typecheck   # 타입 검사 (tsc -b)
npm test            # 계산 엔진·가상 데이터·질문 매칭·이메일 초안 테스트
npm run build       # 타입 검사 + 프로덕션 빌드 (dist/)
npm run preview     # 빌드 결과 미리보기
```

- Node.js 18 이상이 필요합니다. 패키지 관리자는 npm으로 통일합니다.
- 백엔드, 외부 API, API 키, 데이터베이스가 없습니다. `npm install` 후 바로 실행됩니다.
- 린트 명령은 아직 없습니다.

**Windows PowerShell에서 `npm`이 "스크립트를 실행할 수 없으므로…" 오류로 막히는 경우**
PowerShell 실행 정책 때문입니다. 아래 중 하나를 사용하세요.

```powershell
# 방법 1: 현재 사용자 계정만 로컬 스크립트 허용 (관리자 권한 불필요, 1회)
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned

# 방법 2: 정책 변경 없이 실행
npm.cmd run dev
```

- 새로고침·뒤로가기에도 탭이 유지되며, 키보드 ←/→/Home/End로 탭을 이동할 수 있습니다.

**언어·테마**

- 라이트/다크 전환: 처음 방문 시 OS 설정을 따르고, 선택한 값은 브라우저(localStorage `hrsg.lang`, `hrsg.theme`)에 저장됩니다.

**반응형**
- 데스크톱 다중 열 → 태블릿 2열 → 모바일 1열로 재배치됩니다.
- 모바일에서는 헤더 고정이 해제되고 탭 이름이 짧게 바뀝니다(예: "계산기").
- 넓은 표는 카드 안에서만 가로 스크롤되며, 페이지 전체에는 가로 스크롤이 생기지 않습니다.

## 탭 1 — AI 질의응답

> **실제 AI, RAG, 기업 문서 검색은 연결되어 있지 않습니다.** 모든 답변 영역에 `시연용 답변 · 실제 AI/RAG 미연동` 배지가 표시됩니다.

**화면 구성**
- 대화창(질문 입력·전송, 대화 이력, 대화 지우기)
- 추천 질문
- 데이터 출처 및 신뢰성 카드
- 추가 데이터 안내 카드(체크리스트 수령 현황 + 이동 버튼)

**추천 질문 (5개)**
1. HRSG 배압이 증가하면 발전 성능에 어떤 영향을 주는가?
2. 현재 조건에서 세정 필요성을 판단하려면 어떤 데이터가 필요한가?
3. 드라이아이스 세정과 고압수 세정의 차이는 무엇인가?
4. Pinch Point와 Approach Point는 각각 무엇을 의미하는가?
5. 세정 전후의 성능 개선 효과를 검증하려면 어떤 자료가 필요한가?

**동작**
- 추천 질문을 누르면 사전 작성된 시연용 답변이 표시됩니다.
- 직접 입력한 질문은 준비된 질문과 대조합니다(`src/lib/qaMatch.ts`).
  - 문장이 같으면 그 답변을 보여줍니다.
  - 핵심어가 맞으면 "입력 문장과 가장 가까운 준비 질문에 대한 답변: …"이라고 **어느 질문에 대한 답인지 밝히고** 보여줍니다.
  - 맞는 질문이 없으면 "실제 AI가 연결되어 있지 않아 답변을 생성할 수 없다"고 안내하고 준비된 질문 목록을 보여줍니다.
- Enter 전송, Shift+Enter 줄바꿈입니다(한글 입력 조합 중 Enter는 전송하지 않음). 빈 입력이면 전송 버튼이 비활성화됩니다.

**답변 구성**
- 일반 개념 설명
- 관련 수치 표
- 추가로 필요한 데이터
- 관련 탭 이동 버튼(계산기·체크리스트·세정 전후 검증)
- 답변 근거 및 신뢰성(접기)

**답변 규칙**
- 배압만으로 세정이 반드시 필요하다고 단정하지 않습니다.
- 예시 계산을 실제 손실처럼 표현하지 않습니다.
- 확인되지 않은 기업 문서나 기술 가이드를 인용하지 않습니다.
- 답변 속 숫자는 따로 적어 둔 값이 아닙니다. **계산기 입력값, 중앙 계산 엔진, 체크리스트 상태, 세정 데이터에서 실시간으로 가져옵니다.** 계산기에서 배압을 280으로 바꾸면 답변의 월간 손실도 45,360,000원으로 바뀝니다.

## 탭 2 — 성능·경제성 계산기

화면 구성: 핵심 KPI 4종 → (좌) 입력 패널 / (우) 게이지·계산 결과·성능 분석 차트·HRSG 개념도·Pinch/Approach·세정 비교·데이터 인벤토리

### 핵심 KPI
| KPI | 기본값 | 데이터 유형 |
|---|---|---|
| 현재 배압 | 320 mmH₂O + 시연용 상태 배지(위험) | 가상 데이터 · 기준값 미확정 |
| 기준 배압 대비 초과분 | 70 mmH₂O | 가상 데이터 |
| 발전 손실 추정치 | 1.05 MW | 예시 계산 |
| 월간 경제적 손실 예시 | 105,840,000원 | 예시 계산 |

### 입력값 (모두 시연용 가상 데이터, 편집 즉시 전체 갱신)
| 항목 | 기본값 | 단위 | 허용 범위 |
|---|---:|---|---|
| HRSG 설비 유형 | F-class | 선택 (F / J) | — |
| 기준 설비 용량 | 150 | MW | 1 ~ 1,000 |
| 운전 부하율 | 90 | % | 1 ~ 110 |
| 현재 배압 | 320 | mmH₂O | 0 ~ 1,000 |
| 기준 배압 | 250 | mmH₂O | 0 ~ 1,000 |
| 배기가스 출구 온도 | 135 | °C | 30 ~ 400 |
| SMP | 140 | 원/kWh | 0 ~ 1,000 |
| 월간 운전 시간 | 720 | h | 0 ~ 744 |
| Drum Pressure | 100 | bar | 1 ~ 250 |
| Economizer 출구 급수 온도 | 150 | °C | 0 ~ 400 |
| 증발기 출구 가스 온도 | 350 | °C | 0 ~ 700 |

- J-class를 선택하면 설비 용량에 **시연용 270 MW**가 채워집니다(실제 설비의 공식 용량 아님). F-class는 150 MW입니다.
- **입력 검증**
  - 빈 값, 숫자가 아닌 값, 음수, 범위 밖 값은 입력란 아래에 오류 문구로 표시됩니다.
  - 그 값에 의존하는 결과는 `—`로 보류되며, 화면에 NaN·Infinity가 나오지 않습니다.
  - `1,000`처럼 쉼표가 들어간 숫자도 받습니다.
- "기본값으로 초기화" 버튼이 있습니다.

### 계산 결과 카드
단계별 식에 실제 대입값을 보여줍니다. 예: `1.05 × 1,000 × 720 h × 140 원/kWh = 105,840,000원`. `예시 계산` 배지와 "임시 계산식 기반 · 실제 설비 성능 및 손실 검증 필요" 안내가 붙습니다.

### 배압 상태 게이지
- 반원형 게이지에 현재 배압 바늘과 기준 배압 표시가 있습니다.
- 시연용 임계값: **270 미만 정상 · 270~300 주의 · 300 초과 위험** (mmH₂O). `기준값 미확정` 배지가 붙습니다.
- 상태는 시연용 표시일 뿐 세정 필요성을 확정하는 진단이 아니라는 문구가 있습니다.
- 판단에 추가로 필요한 데이터(운전 부하, 배기가스 온도 추이, 설비 이력, 설계 조건)를 함께 표시합니다.

### 운전 조건 및 성능 분석 차트
- 상단 요약: 운전 출력 예시(용량 × 부하율), 발전 손실 예시와 출력 대비 손실 비율, 월간 손실 예시, 배기가스 출구 온도
- 차트: 배압에 따른 월간 손실 예시 곡선(백만원)
  - **KPI와 같은 계산 함수**로 그리므로 현재 배압 지점의 값이 KPI와 같습니다.
  - 정상·주의·위험 구간 음영, 기준·현재 배압 표시선, 툴팁, 범례가 있습니다.

### HRSG 개념도
- 구성요소: Gas Inlet · Superheater · Evaporator(+Drum) · Economizer · Gas Outlet · Steam/Water Flow
- 마우스를 올리거나 클릭하거나 키보드로 고르면 설명과 관련 입력값이 표시됩니다.
- `개념도 · 실제 설비 도면 아님` 표시가 있으며, 실제 설계도나 P&ID가 아닙니다.

### Pinch Point · Approach Point
- 상태: **`분석 대기 — 실제 설계 데이터 및 계산 기준 필요`**
  - 포화온도 산정 기준과 설계 기준값이 확정되지 않아 수치를 계산하지 않습니다.
- 입력값 3종(Drum Pressure, Economizer 출구 급수 온도, 증발기 출구 가스 온도)을 `가상 데이터`로 표시합니다.
- 일반 정의는 "참고용 · 계산하지 않음"으로 보여줍니다.
- 추가로 필요한 설계·운전 데이터 목록이 있습니다.

### 세정 방식별 비용·편익 비교 (가상 데이터)
| 세정 방식 | 가상 세정 비용 | 가상 월간 편익 | 단순 회수 기간(예시 계산) |
|---|---:|---:|---:|
| 드라이아이스 세정 | 30,000,000원 | 38,000,000원 | 0.79개월 |
| 고압수 세정 | 18,000,000원 | 24,000,000원 | 0.75개월 |
| 약품 세정 | 25,000,000원 | 30,000,000원 | 0.83개월 |

- 묶음 막대 차트(백만원)와 표를 함께 보여주고, 툴팁에는 원 단위가 표시됩니다.
- "실제 견적 또는 검증된 경제성 자료가 아님"을 안내합니다.

### 데이터 인벤토리 · 가정값 확인
화면에 쓰인 모든 값을 항목별로 보여줍니다. 대상은 입력값, 가정값(계수·임계값), 세정 비교 데이터, 계산 결과입니다.
- 열: 현재 값 · 단위 · 데이터 유형 · 임시 가정 여부 · 실제 데이터 교체 필요 여부
- 교체가 필요한 항목에는 `실측 데이터 미입력` 또는 `기준값 미확정`이 붙고, 계산 결과에는 "모델 검증 필요"가 붙습니다.

## 탭 3 — 데이터 요청 체크리스트

클라우드라에 요청하거나 향후 확보할 HRSG 데이터 **22개 항목**을 관리합니다.

| 분류 | 항목 수 | 항목 |
|---|---:|---|
| A. 가스터빈 및 운전 데이터 | 5 | 가스터빈 부하·출력 이력, 운전 시간·모드, 배기가스 유량, 배기가스 온도, 부하별 주요 운전 조건 |
| B. HRSG 설계 및 운전 데이터 | 9 | 설비 유형·설계 용량, 배압·차압 측정값, 기준 운전 조건, Drum Pressure, 급수 온도, 배기가스 입·출구 온도, Pinch/Approach 설계값, 설계 사양·운전 기록 |
| C. 세정 및 유지보수 데이터 | 8 | 세정 전·후 운전 데이터, 과거 세정 이력, 세정 방식·작업 조건, 세정 비용, 작업·정지 시간, 세정 전후 성능 비교 자료, 관련 정비 기록 |

**각 항목의 구성**
- 체크박스(검토 여부)
- 항목명과 필요한 이유
- 단위·데이터 형식
- 우선순위(높음·중간·낮음)
- 데이터 상태 선택
- 편집 가능한 비고

**검토 상태와 수령 상태는 따로 관리합니다**
- 체크박스는 팀이 **검토했는지**만 나타냅니다. 체크해도 데이터를 받은 것으로 처리되지 않습니다.
- 데이터 상태: `실측 데이터 미입력`(기본값) · `요청 필요` · `수령 완료` · `검증 필요`
- **검토 진행률** = 검토 완료 항목 수 ÷ 22 × 100 (체크박스 기준)
- **데이터 수령률** = "수령 완료" 항목 수 ÷ 22 × 100 — 검토 진행률과 다른 카드에 따로 표시
- 상태별 항목 수 분포 카드와 분류별 검토 수(예: 검토 2/5)도 표시됩니다.

**자료 요청 이메일 초안**
- 데이터 상태를 **"요청 필요"로 지정한 항목**으로 초안을 만듭니다.
- 초안 구성: 인사, 프로젝트·요청 목적, 분류별 요청 항목과 형식, 단위·기간 안내, 자료 활용 목적, 마무리 인사
- 수신자·발신자는 `[수신자 성함/직함]` 같은 자리표시자로 남기며, 실제 이메일 주소를 만들지 않습니다.
- 제목과 본문을 편집할 수 있고 "제목·본문 복사" 버튼으로 클립보드에 복사합니다.
  - 복사 후에는 "(발송되지 않았습니다)"라고 표시됩니다.
  - 브라우저가 자동 복사를 막으면 직접 선택해 복사하라고 안내합니다.
- **발송 기능은 없습니다.** 초안을 만든 뒤 요청 항목이 바뀌면 경고가 표시됩니다.

## 탭 4 — 세정 전후 검증

> 화면의 전후 비교 수치는 모두 **가상 시나리오**이며 실제 세정 성능이나 검증된 개선 효과가 아닙니다. 이 시나리오는 **계산기 입력값과 분리**되어 있어 계산기 값을 바꿔도 변하지 않습니다.

**기본 가상 시나리오** (`src/data/validationScenario.ts`)

| 지표 | 세정 전 | 세정 후 |
|---|---:|---:|
| 배압 | 320 mmH₂O | 245 mmH₂O (−23.4%) |
| 배기가스 출구 온도 | 135 °C | 112 °C (−17.0%) |
| 발전 성능 변화 예시 | 기준 상태 | +1.1 MW 가정 |
| 세정 비용 | — | 30,000,000원 가정 |

**화면 구성**
- 세정 전후 KPI 비교 4종
  - 각 카드에 `가상 시나리오` 배지가 붙습니다.
  - 실측값이 없으면 `실측 데이터 미입력`이 표시됩니다.
- 배압 비교와 배기가스 출구 온도 비교 막대(변화량·변화율 포함)
- 세정 비용 및 경제성 요약
  - 가상 세정 비용 30,000,000원 ÷ 가상 순편익 1,250,000원/일 = **`24일 · 가상 시나리오 · 예시 계산`**
  - 단순 시연 계산이며 실제 투자회수기간이 아닙니다. 정지 손실·할인율·재오염은 반영하지 않습니다.
  - 계산기 세정 비교의 "월간 편익"과는 별도의 가정임을 안내합니다.
- 누적 순편익 차트: 0~60일 누적 편익에서 비용을 뺀 값(백만원), 손익분기 24일 표시
- 세정 전후 시계열 차트
  - 세정 전 30일 + 세정 후 60일의 가상 시계열입니다. 배압과 배기가스 온도 중 하나를 골라 봅니다.
  - 세정 시점(0일)을 표시선으로 보여주고, 그날은 작업·정지 구간으로 보아 값을 비워 둡니다.
  - X축(경과일)과 Y축(단위)을 명시하고, `시연용 가상 데이터`를 표시합니다.
- 실측 데이터 입력 영역
  - 경과일(−30~60, 0 제외), 배압, 배기가스 온도를 입력합니다.
  - 입력값은 **진한 다이아몬드 점과 `실측 데이터` 배지**로 가상 시나리오와 다르게 표시되고, "검증 전 값"으로 안내됩니다.
  - KPI 카드에 실측 평균(세정 전·후)이 별도로 표시됩니다. 행별 삭제와 전체 삭제가 가능합니다.

## 계산식과 검증값

모든 계산은 UI와 분리된 순수 함수로 **`src/lib/calc.ts`** 한 곳에 있습니다.

| 계산 | 식 | 단위 |
|---|---|---|
| 배압 초과분 | `delta_bp = max(0, input_bp − reference_bp)` | mmH₂O |
| 발전 손실 예시 | `power_loss_mw = delta_bp × 0.015` | MW |
| 월간 손실 예시 | `monthly_loss_krw = power_loss_mw × 1000 × operating_hours × input_smp` | 원 |
| 시연용 배압 상태 | 270 미만 정상 · 270~300 주의 · 300 초과 위험 | — |
| 운전 출력 예시 | 설비 용량 × 부하율 ÷ 100 | MW |
| 출력 대비 손실 비율 | 발전 손실 ÷ 운전 출력 × 100 | % |
| 단순 회수 기간 | 세정 비용 ÷ 월간 편익 | 개월 |
| 손익분기점 예시 | 세정 비용 ÷ 일일 순편익 | 일 |
| 누적 순편익 | 일일 순편익 × 경과일 − 세정 비용 | 원 |
| 전후 변화 | 후 − 전, (후 − 전) ÷ 전 × 100 | 해당 단위, % |

- **`0.015`는 시연용 임시 계수**이며 공학적으로 검증되지 않았습니다. SMP가 이미 원/kWh이므로 월간 손실에서 1000으로 다시 나누지 않습니다.
- 화면 문구 속 계수(0.015)와 임계값(270/300)은 엔진 상수에서 가져옵니다. 엔진 값을 바꾸면 안내 문구도 함께 바뀝니다.

**기본값 검증** (현재 320 · 기준 250 · SMP 140 · 720 h)
- 배압 초과분 **70 mmH₂O**
- 발전 손실 예시 **1.05 MW**
- 월간 손실 예시 `1.05 × 1000 × 720 × 140` = **105,840,000원**

## 데이터 신뢰성 표시 규칙

| 구분 | 모양 | 값 |
|---|---|---|
| 운전 상태 배지 | 채움 캡슐 + 원형 점 | 정상 · 주의 · 경고 · 트립 (+ 시연용 임계값의 `위험`) |
| 데이터 유형 배지 | 점선 사각 캡슐 + 기호 | `가상 데이터` · `가상 시나리오` · `예시 계산` · `기준값 미확정` · `실측 데이터 미입력` · `기능 구현` · `연동 예정` |
| 실측 데이터 배지 | 진한 채움 사각 캡슐 | `실측 데이터` — 가상 값과 다른 모양으로 구분 |
| 데이터 수령 상태 배지 | 좌측 굵은 막대 | `실측 데이터 미입력` · `요청 필요` · `수령 완료` · `검증 필요` |

- 운전 상태(설비가 어떤 상태인가)와 데이터 유형(이 값을 얼마나 믿을 수 있는가)은 서로 다른 모양으로 구분됩니다.
- 실측값이 없는 곳에는 가상값을 실측값처럼 채우지 않습니다.
- 연결되지 않은 기능(AI/RAG, 데이터베이스, 이메일 발송)은 연동된 것처럼 표시하지 않습니다.

## 알려진 한계와 향후 과제

**아직 구현되지 않은 기능**
- 실제 AI/RAG 연결: 현재는 사전 작성 답변 + 키워드 매칭입니다.
- 상태 저장·공유: 체크리스트, 팀 검토, 실측 입력, 대화 이력은 새로고침하면 사라집니다.
- 실제 이메일 발송: 초안 작성·복사만 가능합니다.
- 실측 데이터 파일(CSV) 가져오기, 단위 변환(mbar ↔ mmH₂O)
