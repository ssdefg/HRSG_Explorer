## 빠른 시작

```bash
npm install         # 의존성 설치
npm run dev         # 개발 서버 → http://localhost:5173
npm run typecheck   # 타입 검사 (tsc -b)
npm test            # 계산 엔진·케이스 저장·체크리스트·AI 답변 규칙 테스트
npm run build       # 타입 검사 + 프로덕션 빌드 (dist/)
npm run preview     # 빌드 결과 미리보기
```

- Node.js 18 이상, npm 사용. 데이터베이스는 없습니다.
- AI 질의응답의 직접 입력 질문은 참고문헌 RAG 서버(Python)가 켜져 있을 때만 실제 검색·AI 답변을 씁니다. 서버가 꺼져 있으면 기존 시연용 답변 매칭으로 동작합니다.

### 참고문헌 RAG 서버 (선택)

```bash
pip install -r server/requirements.txt
python scripts/build_corpus.py     # HRSG_RAG_참고문헌/*.pdf → rag/corpus.json, rag/doc_map.json
python scripts/build_indices.py    # → rag/embeddings.npy, rag/metadata.json, rag/bm25_index.pkl (CPU 약 1시간)
python scripts/build_bibliography.py  # → rag/bibliography.json (근거 카드의 논문 제목·DOI, 선택)
copy .env.example .env             # .env 에 GEMINI_API_KEY=... 입력 (Google AI Studio 키, 없으면 검색 결과만 표시)
python -m uvicorn server.app:app --port 8000
```

- 답변 생성은 Google Gemini(`google-genai` SDK)입니다. 기본 모델 순서는 `gemini-3.5-flash` → `gemini-3.8-flash`이며, 앞 모델이 과부하(503/504)·한도 초과(429)면 다음 모델로 넘어갑니다. `.env`의 `RAG_MODEL`로 바꿀 수 있습니다.
- `.env`는 `.gitignore`에 들어 있어 커밋되지 않습니다.

- `npm run dev`의 Vite 서버가 `/api` 요청을 `127.0.0.1:8000`으로 넘깁니다. 다른 포트면 `RAG_API=http://127.0.0.1:8001 npm run dev`.
- 검색기(BGE-M3 모델 + 인덱스)는 서버 시작 시 한 번만 메모리에 올리며, 시작에 수십 초가 걸립니다.
- `rag/` 산출물은 참고문헌 원문을 담고 있으므로 커밋하지 않습니다 (`.gitignore`).
- 린트 명령은 아직 없습니다.
- Windows PowerShell에서 `npm`이 "스크립트를 실행할 수 없으므로…"로 막히면 `Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned`를 한 번 실행하거나 `npm.cmd run dev`를 사용하세요.

## 대시보드 / 개요

현재 평가 케이스를 요약하고 다른 화면으로 이동하는 허브입니다. 계산 결과는 계산기와 **같은 중앙 상태**를 참조하므로 값이 서로 다르지 않습니다.

- **AI 어시스턴트**: 대시보드 카드가 아니라 모든 화면의 플로팅 버튼으로 엽니다. 아래 [AI 어시스턴트](#ai-어시스턴트-모든-화면--플로팅과-질문-기록) 참고.

- **상단 상태 표시**
  - 가상 운전 상태(선택 시나리오 + 배압 자동 판별)
  - 활성 경보 수: `src/lib/alarms.ts`에 **정의된 DEMO 규칙만 집계**합니다. 배압 ≥ 270 mmH₂O, 트립 시나리오 선택. 클릭하면 규칙 목록이 보입니다.
  - 데이터 기준 시점: "미정 — 시연 데이터에 측정 시점 없음"
  - 마지막 입력·계산 시각
  - DEMO 표시, "실시간 연동 아님"
- **운전 현황**: 가스터빈 모델(가상), 설비 용량, 차압 ΔP, 현재 배압, 스택 온도, 운전 상태
- **데이터 준비 현황**: 데이터 수령률, 검토 진행률, 필수 데이터 충족, 평가 가능 여부, 부족 데이터 개수
- **성능 및 경제성 요약**
  - 예상 발전 출력 손실, 예상 월간 발전 손실액
  - 세정 필요성 검토 상태: 필수 데이터가 부족하면 `추가 검토 필요`. 배압만으로 확정하지 않습니다.
  - 세정 전후 예상 효과(요약만, 상세는 "세정 전후" 메뉴로 이동)
  - 공법별 비용·편익 요약
- **최근 분석 내역**: 이 케이스에서 저장한 계산 결과 스냅샷만 표시합니다. 없으면 빈 상태 안내가 나오며, 가짜 이력을 만들지 않습니다.
- 현재 평가 케이스, 다음 추천 작업(현재 상태에서 규칙으로 도출)

## 성능·경제성 계산기

### 평가 설정
- **평가 모드**
  - **DEMO 시나리오**: 예시 계산 엔진을 그대로 씁니다.
  - **사용자 입력**: 단위 환산·산술로 정의되는 경제성만 계산합니다. 검증되지 않은 배압→출력 손실 계수(0.015)를 쓰는 항목은 `모델 미연동 · 평가 보류`로 표시합니다.
- **운전 시나리오 (DEMO 프리셋, 공학 기준 아님)**

  | 시나리오 | 현재 배압 | 차압 ΔP | 스택 온도 |
  |---|---:|---:|---:|
  | 정상 | 255 mmH₂O | 22.0 mbar | 106 °C |
  | 경보 (기본값) | 350 mmH₂O | 30.0 mbar | 115 °C |
  | 트립 | 420 mmH₂O | 36.0 mbar | 128 °C |

  배압·차압·스택 온도를 직접 바꾸면 시나리오가 `사용자 지정`으로 바뀝니다.
- **계산 실행 / 재평가 필요**: 입력값(프리셋·설비 유형·모드 포함)을 바꾸면 KPI와 결과 영역이 블러 처리되고 `재평가 필요` 배지가 뜹니다. "재평가 실행"을 눌러야 다시 보입니다. 재평가 전에는 "이 결과 질문하기"·스냅샷 저장을 막습니다. **선택한 시나리오와 배압 기반 자동 판별 상태는 별개의 필드**입니다.
- **이 결과 질문하기**: 입력이 유효하면 계산 결과 스냅샷을 만들고, AI 화면 입력창에 질문 초안과 스냅샷을 첨부합니다. 입력이 무효이면 숫자를 전달하지 않고 입력 보완을 요청합니다.
- **분석 스냅샷 저장**: 대시보드 "최근 분석 내역"에 기록됩니다.

### 입력값 (최종 구현 가이드 §2.3, 모두 DEMO 기본값)
| 섹션 | 항목 | 기본값 | 단위 (선택 가능) | 허용 범위 |
|---|---|---:|---|---|
| A. 설비 및 GT 운전 | 가스터빈 기종 | F-Class | 선택 | F-Class 150 MW / J-Class 270 MW |
| | 정격 설비 용량 | 150 | MW | 50–600 |
| | 운전 부하율 | 100 | % | 30–110 (범위 밖은 30/110으로 보정) |
| | 현재 배압 | 350 | mmH₂O · kPa · inH₂O · mbar | 0–1,200 mmH₂O |
| | 기준 배압 | 250 | mmH₂O · kPa · inH₂O · mbar | 0–800 mmH₂O |
| | HRSG 가스측 차압 ΔP | 30.0 | mbar | 0–200 |
| | 월간 가동시간 | 720 | h | 0–744 |
| | 스택 배기가스 온도 | 115 | °C · °F | 60–250 °C (300 °C 초과는 트립 위험 경고) |
| | 기준 스택 온도 (세정 직후) | 105 | °C · °F | 60–250 °C · 세정 필요도 지수용 |
| B. HRSG 열역학 | 고압 드럼 압력 | 110 | bar(a) · kPa · psia | 10–200 bar |
| | 절탄기 출구 급수온도 | 290 | °C · °F | 50–370 °C |
| | 증발기 출구 가스온도 | 320 | °C · °F | 100–600 °C |
| | 핀치/어프로치 설계값 | (선택, 비어 있음) | °C | 0–100 |
| C. 경제성 기준 | SMP | 140 | 원/kWh | 50–500 |
| | 세정 시 회수 출력 | 2.1 | MW | 0–30 |
| | 드라이아이스 세정비용 | 35,000,000 | 원 | 0–300,000,000 |
| | 세정 정지 일수 | 2 | 일 (정수) | 0–30 |
| | 간접 비용 | 0 | 원 | 0–300,000,000 |

- 단위를 바꾸면 같은 물리량이 되도록 입력란 값을 환산합니다(1 mmH₂O = 0.00980665 kPa). 계산은 항상 기준 단위로 합니다.
- **폼 검증 (가이드 §3.1)**: 음수 → "음수는 입력할 수 없습니다." 후 포커스를 벗어나면 직전 유효값 복원 · 빈 값/문자 → "유효한 숫자를 입력하세요."(적색, 계산 보류) · 부하율 범위 밖 → 30/110 %로 보정 · 현재 배압 < 기준 배압 → 앰버 경고, 초과분 0으로 연산 · 스택 온도 300 °C 초과 → 적색 "스택 온도 안전 한계 초과 (트립 위험)".
- 가상 모델명(DEMO-GT-150/270)과 용량(150/270 MW)은 실제 제조사·발전소 사양이 아닙니다. 대시보드·계산기·AI에 같은 값이 표시됩니다.
- **입력 검증**
  - 천 단위 쉼표를 받습니다.
  - 음수·범위 밖·빈 값(필수)·문자열은 입력란 아래에 사유를 표시합니다.
  - 잘못된 입력을 0으로 바꾸지 않습니다.
  - 그 값에 의존하는 결과는 `—`(내부 null) + `산출 불가`로 표시하고 마우스를 올리면 사유가 나옵니다. 이전 유효 결과를 남기지 않습니다.
- 각 입력란에 출처 표시가 붙습니다: `DEMO 기본값` / `수정됨 · 가상값` / `사용자 입력`.

### 결과 영역
- 핵심 KPI 4종(현재 배압 · 초과분 · 발전 손실 · 월간 손실)
- 배압 게이지: 시연용 임계값 270/300, `기준값 미확정`
- 계산 결과 카드: 배압 기반 손실과 세정 경제성을 단계별 식과 함께 **각각 별도 행**으로 보여줍니다. 표시 순서는 유효 가동시간, 추가 매출, 정지 손실, 초기 투자, 순편익, 월간 순증분 편익, 회수 기간, 손익분기입니다.
- 배압별 월간 손실 곡선: 사용자 입력 모드에서는 `모델 미연동`
- HRSG 개념도
  - 가스 흐름(회색 실선), 급수 흐름(파란 점선), 증기 흐름(주황 점선)을 구분해 그립니다.
  - `HRSG 개념도 · 시연용 · 실제 설비 도면 아님`
- Pinch/Approach: IAPWS-IF97 포화선 식으로 드럼 압력의 포화온도 Tsat를 구해 Pinch = T_eva,gas,out − Tsat, Approach = Tsat − T_eco,water,out를 계산하고 설계 기준(8–15 °C / 5–12 °C)과 비교합니다. 기본값에서 Tsat ≈ 318.1 °C.
- 세정 공법 비교: 드라이아이스 / 고압수 / **화학(약품)** 세정. 가상 데이터, 묶음 막대 + 표.
- 세정 전후 상세 분석은 [세정 전후](#세정-전후) 메뉴로 옮겼습니다. 계산기 입력값을 바꾸면 그 화면의 회수 출력·경제성·손익분기도 함께 바뀝니다.
- 데이터 인벤토리: 모든 입력·가정값·세정 데이터·계산 결과의 출처와 교체 필요 여부

## AI 어시스턴트 (모든 화면 · 플로팅)과 질문 기록

모든 화면 오른쪽 아래의 주황색 버튼으로 여는 **HRSG AI Assistant**입니다. 예전 대시보드 최상단 AI 카드를 대체합니다 (`#qa` 주소는 어시스턴트를 엽니다).

- **창 모드**
  - 기본 플로팅 창(420×600, 화면이 낮으면 축소)과 오른쪽 전체 높이 **사이드 패널**(520px)을 헤더 버튼으로 전환합니다.
  - 1100px 이상에서는 패널을 열면 메인 콘텐츠가 패널 너비만큼 줄어 데이터가 가려지지 않습니다. 더 좁으면 오버레이입니다.
  - 640px 이하에서는 전체 화면으로 열립니다. Esc로 닫힙니다. 모드는 다음 방문에도 기억합니다(`hrsg.chatMode`).
- **페이지 이동해도 유지**: 어시스턴트는 App 최상위에 한 번만 렌더링되고, 상태는 Workspace 컨텍스트(`chatOpen`·`chatMode`·`activeId`·`attachment`)에 있습니다.
- **대화 관리 (케이스별)**: 새 대화, 대화 기록 목록, 불러오기, 삭제, 질문·답변 복사. 케이스를 바꾸면 그 케이스의 대화로 바뀝니다. 대화는 케이스 데이터와 함께 이 브라우저(localStorage `hrsg_explorer_v1_cases`, 버전 4)에 저장됩니다. 버전 3의 단일 대화는 첫 대화로 옮겨집니다.
- **답변 엔진은 기존 그대로**: `/api/ask` → BM25 + BGE-M3 가중 RRF → 문서당 2개·상위 8문단 → Gemini. 가중치는 바꾸지 않았습니다.
  - Gemini 키가 없거나 거절·오류면 **검색 전용 모드**로 근거 문단만 표시합니다.
  - 서버에 연결할 수 없으면 오류와 "다시 시도"를 표시합니다. 사전 작성 답변으로 대신하지 않습니다(이전 대화에 저장된 시연용 답변은 그대로 보여 줍니다).
- **현재 화면 연결**
  - 각 화면의 **"AI에게 질문하기"** 버튼(대시보드 필터 바, 계산기 평가 설정, 체크리스트·세정 전후 상단)을 누르면 어시스턴트가 열리고, 그 화면의 데이터 스냅샷이 첨부되고, 추천 질문이 입력창에 들어갑니다. 전송은 사용자가 합니다.
  - 어시스턴트 입력창의 "현재 화면 데이터 첨부"로도 첨부할 수 있습니다.
  - 스냅샷은 화면 전체가 아니라 질문에 필요한 라벨·값·단위만 담습니다(최대 40항목, `src/lib/aiContext.ts`). 체크리스트 측정값·메모·고객사명·이메일 초안은 넣지 않습니다.
  - 서버(`ContextSnapshot` 스키마)가 길이·항목 수를 검증하고 문자열을 다시 마스킹한 뒤 프롬프트에 "앱 계산값(문헌 아님)"으로만 넣습니다. 문헌 검색은 질문 문장만으로 합니다.
- **추천 질문**: 화면마다 6개(`src/data/assistantPrompts.ts`).
- **근거 문헌 카드**: 논문 제목·페이지(기본) → 펼치면 DOI 링크, 파일명, 검색 방식(BGE-M3·BM25 각 순위와 RRF 점수), 인용 검증(답변에 [n]이 있는지), 원문 문단. 답변 속 [n]을 누르면 해당 카드가 열립니다.
  - 제목·DOI는 `python scripts/build_bibliography.py`가 `HRSG_RAG_참고문헌_목록.xlsx`에서 만든 `rag/bibliography.json`에서 읽습니다(42편 중 제목 41 · DOI 23). 없으면 파일명을 표시합니다.
- **보안**: 질문과 첨부 데이터의 전화번호·이메일·발전소 고유 명칭(+ 체크리스트에 적은 고객사명)을 전송·저장 전에 `[마스킹]`으로 바꾸고, 서버도 한 번 더 마스킹합니다. 답변 수치가 검색 문단·첨부 데이터·질문에 없으면 "출처 외 수치 포함 주의"를 표시합니다.
- **답변 표시**: 굵게·목록·번호 목록을 지원하는 최소 마크다운 렌더러(HTML 해석 없음).
- **질문 기록** (대시보드 하단 카드): 새 답변마다 질문·답변·일시·케이스를 기록 시점 그대로 저장합니다(`hrsg.qaHistory`, 최대 200건). 대화를 지워도 기록은 남습니다.

## 중앙 계산식과 단위

계산식은 키트 `FORMULAS.md` 를 따릅니다 (앱에 별도 계산식 없음 — `src/lib/calc.ts` 에는 변화율·평균·누적 곡선 같은 표시용 보조 함수만 남았습니다).

| 계산 | 식 (키트) |
|---|---|
| 초과 압력 | `max(0, HRSG 차압 − 설계, GT 배압 − 설계)` [mbar] — 더 큰 초과분 하나 (이중 계산 방지) |
| 출력 손실 | `GT 정격 × 0.08 %/mbar × 초과 압력 × 부하율 + ST 정격 × 0.12 %/°C × 스택 초과 × 부하율` |
| 월간 금액 | `MW × 월간 가동시간 × 전력 단가(원/MWh)` |
| 세정 필요도 | `100 × (0.5·HRSG 차압 + 0.25·GT 배압 + 0.25·스택 온도)` 의 설계 대비 초과 비율 |
| 회수 출력 | 공법 회수율만큼 세 지표의 초과분이 줄어든 뒤의 손실 감소분 (회수율이 없으면 목표 회수 출력) |
| 정지 손실 | `(GT + ST 정격) × 부하율 × 정지일수 × 24 h × 단가 × 2 %` |
| 총투자 · 회수기간 · 손익분기 | `세정 비용 + 간접 비용 + 정지 손실` · `총투자 ÷ 월간 편익` · `회수기간 × 월간 가동시간 ÷ 24` |
| 핀치 / 어프로치 | IAPWS-IF97 Region 4 포화온도 (드럼 압력 + 1.01325 bar), 판정: 어프로치 < 0 위험 · 설계 ± 3 °C 밖 주의 |

- 판정 구간(정상·주의·위험)은 키트 GT 등급 지표를 기준 배압·기준 스택 온도로 다시 맞춘 값입니다. 종합 판정은 세 지표 중 가장 나쁜 것입니다.
- 공법은 「회수기간이 가장 짧은 공법 (가정 기준, 추천 아님)」·「연간 순편익 최대」로만 표시합니다.

기준·검증된 모델이 필요합니다.
  - 차압 ΔP는 표시·기록용 입력이며 계산에 쓰이지 않습니다.
- **저장 한계**: 이 브라우저(localStorage)에만 저장됩니다. 팀 공유가 필요하면 서버 저장소, 사용자 인증, 작성자·수정 시각 기록이 필요합니다.
- **입력 데이터 간 연결 없음**: 체크리스트의 측정값과 계산기 입력값은 서로 자동으로 연결되지 않습니다. 실데이터를 받은 뒤 연결 규칙(단위 변환·기간 평균)을 정해야 합니다.
- **기타 미구현**: 실제 이메일 발송, CSV 가져오기·단위 변환(mbar ↔ mmH₂O), 린트 설정
- **검수 기준**: 김예원·구은서 원본 검수 문항은 미제공 상태라 초안으로 대체했습니다. 원본을 받으면 `docs/dev/REVIEW_CRITERIA.md`에서 교체하세요.
